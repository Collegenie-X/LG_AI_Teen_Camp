# LG AI 청소년 캠프 — 자료 저장소

**최상위 = 주제(무엇에 관한 자료인가)**, **하위 = 기능(문서 / 영상 / 양식 …)** 으로 나눴습니다.

```

05_배경지식-AI시대/  수업 도입·문제의식용 AI 시대 담론
06_창업-해커톤/      창업 사례 · 해커톤 · 청소년 창업학교
07_만들기-도구/      바이브코딩 · AI 활용 · 영상 제작
```

## 새 자료 넣는 규칙

1. **무엇에 관한 자료인가** → 최상위 번호 폴더 선택
2. **어떤 형태인가** → `문서/` 또는 `영상/` 하위 폴더에 넣기
3. 새 팀 아이템이 생기면 `04_프로젝트-주제/<아이템명>/{문서,영상}/` 을 만들기

## ⚠️ 정리 과제

- **완전히 동일한 파일 2쌍** (md5 일치) — 하나씩만 남기면 됩니다.
  - `02_강의자료/2일차/Vibe_Coding_Sketchbook.pdf` ↔ `02_강의자료/워크시트-가이드/[아이디어-카탈로그]-Vibe_Coding_Sketchbook.pdf`
  - `04_프로젝트-주제/DeepQ-IB논서술형/영상/` 의 `[DeepQ-동기부여]-중학교 선행학습한…` ↔ `[DeepQ]-논서술형-중학교 선행학습한…`
- 영상 약 4.2GB 가 Git LFS 없이 일반 Git 으로 추적됩니다 (`.git` 4.5GB, 최대 파일 98.2MiB — GitHub 100MiB 한도 직전).
