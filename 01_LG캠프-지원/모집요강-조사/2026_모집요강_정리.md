## 2. 참가비

- 서울대학교 교육과정부터 미국 교육과정까지 **전액 무료**

## 3. 지원 자격 (2026년 기준)

- 초등학교 6학년 ~ 중학교 2학년 청소년
- AI를 활용한 문제해결 팀 프로젝트에 참여하여 소통하고 협동하고자 하는 청소년

**유의사항**
- 인적사항(생년월일, 전화번호, 소속 등)에 허위 내용 기재 시 신청 자동 취소
- 접수 시점에 초6 ~ 중2 학생만 지원 가능

## 4. 지원 유형 및 팀 구성

- **개인**으로 지원 (팀 구성은 주최 측에서 편성)
- 기획자 2명 + 개발자 2명 = 4인 1팀
  - **기획자**: AI에 관심이 높고 문제를 관찰하고 새로운 해결 방법을 찾는 것을 좋아하는 팀원
  - **개발자**: AI 기술을 활용해 해결 방법을 직접 구현하는 것을 좋아하는 팀원

## 5. 지원자 등록 및 지원서 작성

- 홈페이지(www.lgaiyouthcamp.or.kr)에서 지원자 등록 후 지원서 접수
- 지원자 등록은 **학생 본인만** 가능
- 법적 보호자 동의 필요 → **보호자 명의 휴대폰 본인인증** 진행

**지원서 주요 항목**
1. 팀 프로젝트 역할 선택 (기획자 / 개발자)
2. '나만의 AI 문제 해결 아이디어' 주제 영상 제작 후 유튜브 URL 제출
3. 그 외 지원서 양식에 맞춘 답변 작성

> 상세 작성법: 메인 > 지원서 접수 최상단 "지원서 작성방법 다운로드" (지원자 로그인 필요)

## 6. 동영상 제출 가이드 ⚠️

- **길이**: 1분 이상 ~ 3분 미만
- **내용**: 나만의 AI 문제해결 아이디어 (지원서 작성방법 파일에서 확인)
- **촬영 방식**: 해당 아이디어를 **지원자가 직접 설명하는 모습**을 담아 촬영
- **참가자 본인이 영상에 출연하지 않을 경우 선발에서 제외됩니다.**
- 유튜브에 **'일부공개(Unlisted)'** 로 업로드한 후 URL 제출
- 동영상의 **자막을 추출하여 지원서에 입력**해야 함
  - 유튜브 영상 하단 설명란의 '더보기' 클릭 → 자막 확인

## 7. 심사 기준

## 10. 지원서 작성방법 (상세)

> 공식 "지원서 작성방법" 파일은 홈페이지 로그인 후 다운로드 가능합니다.
> 아래는 [LG_AI_청소년캠프_조사.md](LG_AI_청소년캠프_조사.md)에 정리된 **직전 기수(3기) 요강 원문 기준** 내용으로,
> 4기(2026) 공식 파일에서 문항 수·글자 수를 반드시 재확인하세요.

### 10-1. 제출물 구성

심사는 사실상 아래 3가지가 전부입니다.

| 제출물 | 분량 |
|---|---|
| ① 지원 영상 (유튜브 일부공개 URL) | 1분 이상 ~ 3분 미만 |
| ② 영상 자막(스크립트) | 2,000자 이내 |
| ③ 역할 기술서 | 총 1,600자 (300+300+500+500) |

### 10-2. 역할 기술서 문항

**공통 문항**
1. 나 자신을 소개해주세요. **(300자 이내)**
   - 성향, 관심사, 취미, 교내외 활동, 영향을 준 책과 그 이유 등
2. 팀 프로젝트는 4명이 한 팀입니다. 나와 다른 성향·능력을 가진 팀원들과 어떻게 협업할지 구체적으로. **(300자 이내)**

**기획자 선택 시**

3. 기획자로서 자신의 특기와 장점 **(500자 이내)**
4. 그 특기·장점을 살린 경험을 구체적으로 **(500자 이내)**
   - 예시 소재: 글쓰기(시/에세이/일기), 발명, 자원봉사, 인터뷰·시장조사, 구체적 계획 수립(상품 기획·일정 조정), 디자인, 발표 경험

**개발자 선택 시**

3. 개발자로서 자신의 특기와 장점 **(500자 이내)**
4. 그 특기·장점을 살린 경험을 구체적으로 **(500자 이내)**
   - **필수 기재: 개발 언어 / 개발 툴(이름 및 버전) / 구현한 기능** — 누락 시 감점

> 기획자·개발자를 **중복 선택**하면 양쪽 문항을 모두 작성해야 하고, 영상에서도 두 역할을 모두 설명해야 합니다.

### 10-3. 역할별 실제 업무 정의 (기술서 작성 시 이 표현에 맞춰 쓰면 유리)

- **기획자**: 문제 찾기 사전조사 → 경험을 살린 아이디어 제안 → 전문 지식 조사로 해결 방안 구체화 → 협의 내용 시각화(도표·그림·화면 디자인) → **AI 학습용 데이터 수집** → 과정 계획·기록·단계별 발표 준비
- **개발자**: 활용 가능한 기술 조사 → 우리 팀이 구현 가능한지 검토 → **AI 알고리즘 선택** → 1차 프로토타입 개발 → 개선 반영 2차 개발 → 성능 향상 및 최종 완성

### 10-4. 자막(스크립트) 작성

- 유튜브 **자동 자막을 추출**해 지원서에 붙여넣기
- **2,000자 이내**, 타임스탬프 제거 및 띄어쓰기 정리
- 영상에서 말한 내용 전체가 텍스트로도 심사되므로 **대본을 글로 먼저 쓰는 것이 유리**

### 10-5. 접수 관련 규칙

- **개인 지원만** 가능 (팀 지원 없음), **1인 1지원서·중복 지원 불가**
- 지난 기수 지원자의 **재지원 가능**
- **지원서 작성/제출은 PC에서만 가능** (모바일·태블릿 불가)
- 최종 제출 후 **수정·삭제·열람 모두 불가** → 임시저장 상태에서만 수정 가능
- 만 14세 이상은 **본인 명의 휴대폰 필수**, 만 14세 미만은 보호자 명의 가능
- 소속 제한 없음 (대안학교·국제학교·홈스쿨링 가능), 외국 국적자도 지원 가능
- 성인(학부모)은 지원자 등록 불가 — 문의는 비로그인 1:1 문의 이용

### 10-6. 실격 사유

1. 지원자 본인이 영상에 출연하지 않음 (얼굴·목소리 없음)
2. 유튜브 링크와 원본 파일이 **둘 다** 재생 불가
3. 홈페이지 제공 양식이 아닌 파일로 역할 기술서 제출
4. 지원서 허위 기재
5. 합숙 또는 최종 발표·수료식 불참 → 참여·수료 불가

### 10-7. 작성 전략 요약

- 심사 기준 5개 중 **3개(협업 의지 / 열정과 태도 / 역할별 역량·경험)** 는 아이디어가 아니라 **사람**을 봅니다.
  → **아이디어 : 역할 증명 = 5 : 5**로 분량을 배분하세요.
- 협업 문항(300자)이 숨은 승부처 — 심사 기준의 '협업 의지'가 정확히 여기서 채점됩니다.
- "AI로 환경오염 해결" 같은 **남의 문제·무한 범위** 주제는 탈락권. 내가 직접 겪은 좁은 문제에서 출발하세요.
